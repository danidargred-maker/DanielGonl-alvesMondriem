# Título

Na recriação da obra apresentada no exercicio, painel de mondriem, usei a ferramenta medida no adobe illustrator para medir e identificar a posição de todos os elementos presentes na obra. 
No seguimento do projeto eu decidi usar um fundo totalmente preto em vez das linhas, representando assim a obra com varios quadrados brancos, através do rect() até formar a ilustração desejada, à escessão do vermelho, amarelo e azul. Em seguida usei o rect() novamente para criar as formas em falta e o fill() para preencher as mesmas com cor através do RGB.
Por fim usei o random() para recriar a textura granular no background e o for() para criar a variavel das sombras que a imagem apresenta.
